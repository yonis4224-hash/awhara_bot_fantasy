# أوهارا - المدرب الأفضل 🤖⚽

بوت ديسكورد كرة قدم لمحاكاة إدارة الفرق والدوريات والمباريات بتكتيكات متقدمة.

## الميزات

- **✅ سجل كمدرب** - اختر فريقك من 12 نادياً عالمياً بقوائم 2026
- **💰 اقتصاد داخلي** - ميزانية لشراء/بيع اللاعبين + نقاط خبرة للتطوير
- **⚡ تطوير اللاعبين** - 5 مهارات تدريبية ترفع التقييم والقيمة السوقية
- **🔒 تكتيكات مخفية** - تشكيلة، خطة لعب، ومفتاح خططي (سري)
- **⚔️ محاكاة مباريات ذكية** - تأخذ بعين الاعتبار: قوة اللاعبين، التدريب، التكتيكات، المفاتيح الخططية، والمفاجآت
- **🏆 دوريات كاملة** - نظام دوري (ذهاب وإياب) مع جدول ترتيب
- **🔄 سوق انتقالات** - بيع وشراء اللاعبين بين المدربين

## الأندية المتاحة

ريال مدريد، برشلونة، مانشستر سيتي، ليفربول، بايرن ميونخ، باريس سان جيرمان، إنتر ميلان، ميلان، يوفنتوس، أياكس، بورتو، الهلال

## التثبيت والتشغيل

### المتطلبات
- Node.js v16+
- Discord Bot Token

### الخطوات

1. **نصب المتطلبات**
   ```
   npm install
   ```

2. **إنشاء ملف البيئة**
   انسخ `.env.example` إلى `.env` واملأ القيم:
   ```
   DISCORD_TOKEN=توكن_البوت_هنا
   CLIENT_ID=معرف_البوت_هنا
   PREFIX=!
   ```

3. **تشغيل البوت**
   ```
   npm start
   ```

## آلية المحاكاة

محرك المباريات يأخذ بعين الاعتبار:
1. **متوسط تقييم اللاعبين** الأساسيين (هجوم/وسط/دفاع)
2. **التشكيلة** - بعض التشكيلات تتفوق على أخرى
3. **خطة اللعب** - هجومي/دفاعي/مرتد/استحواذ (لكل منها مميزات وعيوب)
4. **المفتاح الخططي** (سري) - نظام مقص-ورقة-حجر من 12 مفتاحاً
5. **التدريب المسبق** - إنفاق XP قبل المباراة يعزز الفريق
6. **عامل المفاجأة** - احتمال upset (فوز الضعيف على القوي)
7. **العقوبات التكتيكية** - هجوم بدفاع ضعيف = عقاب، دفاع بهجوم قوي = عقاب

## المفاتيح الخططية

12 مفتاحاً سرياً مقسمة على 4 استراتيجيات:
- **A** = أجنحة (A1 حذر، A2 متوازن، A3 هجومي)
- **B** = اختراق وسط (B1 حذر، B2 متوازن، B3 هجومي)
- **C** = كرات طويلة (C1 حذر، C2 متوازن، C3 هجومي)
- **D** = تمرير سريع (D1 حذر، D2 متوازن، D3 هجومي)

كل مفتاح يهزم مفاتيح معينة ويخسر أمام أخرى.
